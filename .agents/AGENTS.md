# Gold Coast Solar & Energy Solutions - Workspace Configuration

This directory is configured for the **Gold Coast Solar & Energy Solutions** placeholder website and hosting testing workspace.

## Project Summary
- **Domain:** wherezwollie.com
- **Tech Stack:** HTML5, Vanilla CSS3 (Dark Glassmorphism), Vanilla JS
- **Repository:** https://github.com/wherezwollie/wherezwollie.github.io
- **Key Sections:** Home, About Me, Solar Brands (Fronius, Enphase, Sungrow, REC, LONGi, Tesla), Savings Calculator, Multi-step Quote Wizard, Contact Info, Hosting Diagnostics.

## Developer Instructions
- Keep all edits responsive and styled with CSS variables in `styles.css`.
- Ensure `CNAME` (`wherezwollie.com`) remains in the root folder for GitHub Pages custom domain routing.
- When committing changes, push to `origin/main`.
